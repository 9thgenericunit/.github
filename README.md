# .github

Repository di default dell'organizzazione **9th Generic Unit (9GU)**, clan italiano milsim su ArmA Reforger dal 2012.

## Struttura

- [`profile/README.md`](profile/README.md): la presentazione mostrata nella pagina dell'organizzazione su GitHub (chi siamo, principi, come entrare, link).

Il sito ufficiale ([www.9thgenericunit.com](https://www.9thgenericunit.com/)) è un sito statico HTML/CSS/JS, nel repository `9thgenericunit.com`.

## Aggiornamenti

Il profilo riprende i contenuti del sito. Quando cambiano requisiti, percorso di reclutamento o link (Discord, shop, dashboard), aggiorna `profile/README.md` insieme al sito.
